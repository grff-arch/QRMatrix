# QRMatrix

Веб-приложение для создания, просмотра и управления QR-кодами (версия `0.0.4`).

## Запуск

Репозиторий: https://github.com/grff-arch/QRMatrix
Ветка: lab4
Pull Request: https://github.com/grff-arch/QRMatrix/pull/4
Образ: grffarch/qrmatrix:0.0.4
Страница образа: https://hub.docker.com/r/grffarch/qrmatrix

git clone -b lab4 https://github.com/grff-arch/QRMatrix
cd QRMatrix
docker compose up -d
